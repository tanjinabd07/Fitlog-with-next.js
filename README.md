### Project name
Fitlog-with-next.js
### Short description
FitLog is a fitness and workout planning web application built with Next.js, TypeScript, and Tailwind CSS.
Users can explore different workouts, view workout details, save workouts, and create their own daily workout plan.

### Technologies used
Next.js,
React,
TypeScript,
Tailwind CSS,
Lucide React,
Local Storage.

### 5 key features of the project
🏋️ Browse workout exercises

🔍 View detailed workout information

📋 Add workouts to today's plan

💾 Save favorite workouts

✅ Mark workouts as completed
